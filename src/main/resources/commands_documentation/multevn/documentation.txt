To multiply a two-digit number by eleven first add its digits and then put the result digit between two digits of the
number.
If sum is more than 9 add first digit of the sum to the first input number, put second digit of the sum next and finish
with the last digit of input number.
EXAMPLES:
23 x 11 = 2 (2+3) 3 = 253
67 x 11 = 6 (13) 7 = (6+1) 3 7 = 737
